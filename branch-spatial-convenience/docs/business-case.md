# Business case

## Problem

Multi-outlet businesses typically expose location as a directory or map. Customers, however, arrive with an intent: replace a card, withdraw cash, collect an order, see a specialist, return a product, send a parcel, and so on.

## Product thesis

Branch Spatial Convenience converts an outlet network from a geographic directory into a **service-aware decision system**.

`intent → capability → availability → convenience → route`

## Why this creates business value

### Customer
- fewer wrong-outlet visits
- less search friction
- clearer service availability
- better accessibility information
- faster path from need to action

### Operator
- distribute demand across capable outlets
- reduce avoidable support calls
- expose underused outlet capabilities
- create a consistent multi-location experience
- provide a data model that can later connect to queues, appointments, inventory and routing

## Nearest is not the same as convenient

A production recommendation can consider:

- distance
- travel time
- service capability
- opening hours
- queue or wait time
- accessibility
- facilities
- customer preference

The prototype does not claim live queue or travel data.

## Commercial form

The concept can become:

1. a white-label multi-outlet UX layer;
2. an outlet/service management SaaS;
3. a service-aware convenience API;
4. an enterprise integration for existing location systems;
5. an analytics layer for outlet demand and service distribution.

## Initial case study

The Co-op Bank exploration provides the first concrete case: banking audiences, branches, international money-transfer services and a spatial scaffold. The same model can be adapted to healthcare, retail, telecom, logistics, automotive and public-service networks.
